# NexToken / New API 功能對照

目標是以 NexToken 自研 FastAPI 後端實現 New API 的核心營運能力與操作流程。介面採 NexToken 黑黃主題，不複製 New API 原始碼。

## 已完成

- 管理員數據總覽
- 供應商管道新增、編輯及連線測試
- 模型名稱、成本、售價與上下架
- 同模型多路由、優先級、權重、故障切換及冷卻
- 客戶註冊、登入、餘額及人工調整
- 客戶 API Key、RPM 與 TPM 限制
- Chat Completions 串流及非串流
- Image Generations 與按張計費
- 預扣、實際結算、成本、收入及錯誤日誌
- 31 模型能力目錄

## 驗收原則

- 沒有後端資料模型、API、權限與測試的頁面，不標示為完成。
- 供應商或付款功能必須使用合法憑證完成真實端到端測試後，才能標示為可營運。
- `.env`、供應商 Key、付款密鑰與資料庫不得提交至 Git。
